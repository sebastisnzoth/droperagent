## Por qué CJ

Según su [servicio oficial de sourcing](https://cjdropshipping.com/sourcing), CJ permite solicitar búsqueda de productos; en general es gratuito, con límites según nivel de cuenta. Su [FAQ oficial](https://cjdropshipping.com/help-center?keyWord=sourcing+request&navType=search&pageNum=2&searchType=faq) describe **5 solicitudes diarias para el nivel LV1**; esto NO prueba el nivel actual del usuario ni disponibilidad futura. Se deben comprobar condiciones al enviar. [Cómo conseguir una API Key](https://developers.cjdropshipping.com/en/api/start/apikey.html); instalar la app API no crea por sí solo la clave.

**Ya tenemos** `src/cj-readonly-client.js` en GitHub para búsquedas, variantes, inventario y fletes, pero **no está comprobado que haya una clave/token autorizado conectado**. No se instala otra conexión, no se abre cuenta ni se registra ninguna clave en GitHub.

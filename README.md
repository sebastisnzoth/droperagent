# DroperAgent

Um agente inteligente para processamento e distribuição de tarefas/itens.

## Descrição

O DroperAgent é um agente automatizado projetado para gerenciar fluxos de trabalho, processar encomendas e distribuir recursos de forma eficiente.

## Requisitos

- Node.js 18+ 
- npm ou yarn

## Instalação

```bash
git clone https://github.com/sebastisnzoth/droperagent.git
cd droperagent
npm install
```

## Uso

```bash
npm start
```

## Configuração

Criar arquivo `.env` com as variáveis necessárias:

```env
PORT=3000
DATABASE_URL=postgresql://localhost:5432/droperagent
API_KEY=sua_chave
```

## Desenvolvimento

```bash
npm run dev
```
